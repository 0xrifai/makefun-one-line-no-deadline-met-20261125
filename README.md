An entry for the [One Line, No Deadline Met](https://make.fun/bounty/u-markk-st-one-line-no-deadline-met-6adc00ce) bounty on make.fun. The program writes one single-line joke giving an excuse for a missed deadline to `/output/entry.txt`.

## The entry

> I missed the deadline because my laptop asked if I was sure, and I have never been less sure of anything in my life.

## How it works

`main.ts` (Node 22, TypeScript run as-is) writes the line above to the absolute path `/output/entry.txt`. Nothing else is written: no picture, no link, no second line.

Run it with:

```sh
node main.ts
```
